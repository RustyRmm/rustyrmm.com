# rustyrmm.com

The public website for [RustyRMM](https://rustyrmm.com), served by GitHub
Pages from the `main` branch.

One static page (`index.html`) plus screenshots and logos in `img/`. There is
no build step: edit the HTML, push, and Pages publishes it within a minute.

The **Latest agent** version on the page is read in the browser from the
public [rustyrmm-releases](https://github.com/SmugZombie/rustyrmm-releases/releases)
repository.

## Preview locally

```sh
python3 -m http.server 8000     # then open http://localhost:8000
```

## Screenshots

The images in `img/` come from a RustyRMM console with demo devices only (no
customer or personal data).
